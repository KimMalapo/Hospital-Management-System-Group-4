# Hospital Management System

## Project Overview

The Hospital Management System is a desktop application developed to help manage hospital operations, patient records, admissions, room management, and billing.

## Features

- Login and Registration
- Patient Information Management
- Patient Information Search
- Patient Admissions
- Room Management
- Billing Management
- Master Data Management

## Technologies Used

- C#
- .NET
- Windows Forms
- Visual Studio
- SQL Server (if used by the project)

## Project Structure

- **BusinessLogic** – Contains business logic and application services.
- **Model** – Contains data models.
- **UI** – Contains the user interface and application forms.
- **HospitalManagementSystem.Tests** – Contains automated tests.

## Installation and Setup

1. Clone or download this repository.
2. Open `HospitalManagementSystem.slnx` in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the database connection.
5. Make sure the required database is available.
6. Build the solution.
7. Set the UI project as the startup project.
8. Run the application.
